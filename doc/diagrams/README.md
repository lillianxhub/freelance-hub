# Required Diagrams

โฟลเดอร์นี้ต้องมี Diagram ต่อไปนี้ก่อนส่งงาน:

- Use Case Diagram
- Domain Model / Conceptual Class Diagram
- Class Diagram พร้อมตำแหน่ง Design Patterns
- Sequence Diagram อย่างน้อย 3 scenarios
- Activity Diagram
- ER Diagram / Database Schema
- Component Diagram
- Deployment Diagram
- Invoice State Diagram

เก็บ source ของ diagram (เช่น PlantUML หรือ Mermaid) ควบคู่กับไฟล์ภาพที่ export แล้ว
